# GitHub Pages - Instrucciones de Configuración

## Para ver el módulo en línea

El módulo está disponible en: **https://curiousminds123.github.io/Modulo-1/**

### Si GitHub Pages no está habilitado automáticamente:

1. Ve a https://github.com/Curiousminds123/Modulo-1
2. Haz clic en **Settings** (Configuración)
3. En el menú de la izquierda, selecciona **Pages**
4. Bajo "Source" (Fuente), selecciona:
   - **Branch**: `main`
   - **Folder**: `/ (root)`
5. Haz clic en **Save**
6. Espera 1-2 minutos para que GitHub compile el sitio
7. Verás el enlace: `https://curiousminds123.github.io/Modulo-1/`
